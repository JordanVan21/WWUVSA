Project Overview

This is the official website for the Western Washington University Vietnamese Student Association (WWU VSA).

The purpose of this website is to introduce prospective students, current members, alumni, and university partners to WWU VSA. The website should emphasize community, Vietnamese culture, leadership, and student involvement.

This is primarily an informational website, not a social network or enterprise application.

Design Requirements

The Stitch-generated HTML is the design source of truth.

Do not redesign the interface.

Instead:

 Match the layouts as closely as possible.

 Preserve typography, spacing, colors, and hierarchy.

 Preserve responsive behavior.

 Preserve animations where appropriate.

 Only make changes when required for usability, accessibility, or responsiveness.

Changes from the Stitch Design

Please make the following changes while implementing the design:

Viet 101 Section

 Remove the two statistics cards ("15+ Annual Workshops" and "300+ Total Attendees").

 Allow the text and image to use the available space naturally after removing these cards.

Community Partners Section

Only display these organizations:

 Ethnic Student Center (ESC)

 Northwest Vietnamese Student Association (NWVSA)

 Western Washington University (WWU)

Remove any other placeholder organizations (such as U-VSA).

Call-to-Action Section

Remove the large red "Ready to find your place in our community?" section entirely.

The page should transition naturally from the previous section into the footer.

Create a polished, production-ready informational website that faithfully recreates the approved Stitch design while remaining clean, maintainable, responsive, and easy to expand in the future.
